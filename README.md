# Solos Sax (Taller de Solos Sax Tenor)

App Android para practicar solos con sax tenor: metrónomo con progresión (primera, segunda, tercera), aviso de cambio de acorde, guía tipo Guitar Hero y afinador que te escucha por el micrófono. Todo transportado a Si♭.

## Obtener el APK
Al subir este proyecto a GitHub, la acción **Compilar APK** genera `SolosSax.apk` y lo publica en **Releases**. Ábrelo desde el celular y instálalo (permite "instalar apps desconocidas").

La app vive en `app/src/main/assets/index.html`.
